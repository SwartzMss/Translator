# Translator

一款基于 Qt 和百度翻译 API 的 Windows 桌面翻译应用。

## 特性

- 支持多语言互译（自动检测源语言）
- 简洁直观的界面：输入文字 → 选择目标语言 → 点击"翻译"
- 异步网络请求，保持界面流畅
- 错误提示（网络异常、配额超限等）
- 语言交换功能
- 设置保存功能
- 单实例运行，避免重复启动
- 系统托盘，可在后台常驻
- 内置日志记录，日志文件位于 `logs/translator.log`
- 英文文本润色功能（DeepSeek API）

## 使用说明

1. **输入文本**: 在上方文本框中输入要翻译的文本
2. **选择语言**: 
   - "从"下拉框选择源语言（支持自动检测）
   - "到"下拉框选择目标语言
3. **翻译**: 点击"翻译"按钮开始翻译
4. **查看结果**: 翻译结果显示在下方文本框中
5. **其他功能**:
   - 点击"⇄"按钮交换源语言和目标语言
   - 点击"清空"按钮清空输入和输出
   - 点击"设置"按钮配置API密钥
   - 点击"润色"按钮对输入的英文文本进行润色

## 配置百度翻译 API

1. 访问 [百度翻译开放平台](http://api.fanyi.baidu.com/)
2. 注册账号并创建应用
3. 获取 App ID 和 Secret Key
4. 运行应用，点击"设置"按钮
5. 输入 App ID 和 Secret Key
6. 点击确定保存配置
7. 配置信息会保存到程序目录下的 `translator.ini`

## 配置 DeepSeek API

1. 获取 DeepSeek API Key
2. 在应用中点击"设置"按钮
3. （可选）输入 DeepSeek Key 并保存，以启用润色功能

## 代理设置

1. 在"设置"界面勾选 **启用代理**
2. 填写代理地址、端口以及（可选）用户名和密码
3. （可选）指定自定义 CA 证书文件
4. 点击 **设置并保存** 使配置生效

## 构建与运行

1. 确保已安装 Qt6（建议 6.5 及以上版本）
2. 克隆仓库并进入目录
   ```bash
   git clone https://github.com/yourname/Translator.git
   cd Translator
   ```
3. 使用 qmake 或在 Qt Creator 中打开 `Translator.pro` 进行构建
   ```bash
   qmake Translator.pro
   make
   ```
4. 运行生成的可执行文件，在顶部区域输入并保存 App ID 和 Secret Key 后即可开始翻译

## 开发说明

### 核心类

- **MainWindow**: 主窗口类，负责UI界面和用户交互
- **Translator**: 翻译服务类，封装百度翻译API调用
- **Config**: 配置类，定义应用常量和语言列表

### 技术特点

- 使用 Qt6 的现代C++特性
- 异步网络请求，避免界面卡顿
- 完整的错误处理和用户提示
- 支持设置持久化保存
- 响应式UI设计

## 常见问题

### 错误代码说明

- 52001: 请求超时
- 52002: 系统错误
- 52003: 未授权用户
- 54000: 必填参数为空
- 54001: 签名错误
- 54003: 访问频率受限
- 54004: 账户余额不足
- 58000/58002: 不支持该语种翻译
- 58001: 翻译文本过长
